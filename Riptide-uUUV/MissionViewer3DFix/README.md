# Project Title

BAE Riptide MissionViewer

## Description

The MissionViewer is used as a post mission analysis tool to view MOOS_DB Variable values logged during
misison execution. The program is designed to Analyze .alog and .pid files generated by the BAE Riptide UUV family of systems.

## Getting Started

### Dependencies

* The following python libraries are required to run the MissionViewer.py:
    * numpy
    * pandas
    * matplotlib
    * scipy
    * mpl_toolkits
    * PIL
    * 

### Installing

* Download MissionViewer Folder to local machine
* Install Library Dependencies
    * Using Conda:
        ```
        conda install numpy pandas matplotlib scipy pillow
        ```
    * Using pip:
        ```
        pip install numpy pandas matplotlib scipy pillow
        ```

### Executing program

* Run program using python
```
cd path\to\MissionViewer
python MissionViewer.py
```
